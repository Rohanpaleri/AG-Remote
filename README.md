# AG Remote

An elegant, open-source Android wrapper for [Antigravity](https://antigravity.google.com/).

AG Remote turns the Antigravity web interface into a native-feeling Android application. It provides a seamless, full-screen experience with enhanced reliability for mobile connections.

## ✨ Features

*   **Native Feel:** Full edge-to-edge display with custom splash screens and loading indicators.
*   **Offline Resilience:** Custom built-in offline screens that intelligently auto-reconnect the moment your network returns. No more ugly browser error pages.
*   **File Upload Support:** Seamless integration with the native Android file picker for attaching media and files directly to your agent.
*   **Security First:** Because this is a WebView wrapper, all Google OAuth sign-ins are handled directly and securely by Google. The app does not store or have access to your credentials.

## 📥 Installation

1. Go to the [Releases](https://github.com/Rohanpaleri/AG-Remote/releases) page of this repository.
2. Download the latest `AG Remote.apk` file to your Android device.
3. Open the downloaded file and install it (you may need to allow "Install unknown apps" from your browser/file manager).

## 🛠️ Tech Stack

*   **Language:** Kotlin
*   **Minimum SDK:** Android 7.0 (API 24)
*   **Target SDK:** Android 15 (API 36)
*   **Core API:** `android.webkit.WebView`, `ConnectivityManager`
